# Clio 多账号额度展示

## 最终范围

识别 Claude Code 与 Codex 的多个已有登录账号，并列展示每个账号的已用额度、套餐、更新时间、重置时间及查询状态。读取 Orca 写入的 `claude-profiles/selected-host` 指针，标注 Orca 当前使用的 Claude 账号；空指针对应系统默认账号，指针不存在时不标注。Codex 的选中状态仅存于 Orca 内部数据库，不做标注。不增加账号切换或选中账号的功能，也不测试切号流程。

## 接入方案

读取系统默认目录、Orca 托管目录，以及用户添加的配置目录。通过账号身份去重；目录只是查询上下文。Claude 使用账号和组织标识，Codex 使用账号标识。未知身份不得冒充系统账号。

Claude Code 与 agy 的额度统一来自状态栏接入：状态栏命令按运行时的配置目录（Claude 为 CLAUDE_CONFIG_DIR）或推送中的邮箱（agy）归属账号，Claude 另读取客户端写入的本地额度缓存。Clio 不调用这两个客户端查询额度，也不提供手动刷新。

只有 Codex 没有状态栏推送，按「Codex 查询频率」（默认每 30 分钟）自动传 CODEX_HOME 调用 Codex CLI 查询；凭据由客户端管理。查询与缓存按账号保存；失败显示未知，缓存有实际更新时间，不把未知显示成零。移除目录仅移除 Clio 接入记录。

## 展示边界

额度卡片按账号显示，历史 Token、费用表示本机汇总。主面板移除历史活跃热力图，账号额度采用紧凑布局，身份与套餐在首行，5 小时与本周已用百分比及进度条并列，下方直接显示各窗口的数据获取时间与重置倒计时。账号行右侧显示该账号额度的实际获取时间，读取缓存不更新时间；跨日数据标明日期。同一快照里的两个窗口共享获取时间。状态和重置次数通过悬停查看。菜单栏两工具圆环同步显示已用比例，保留默认账号口径，提示中标明默认账号。账号较多时额度区域可滚动。

## 验证

账号按 Claude Code、Codex、Antigravity 分组排列，组内沿用发现顺序。每个账号结构一致，未返回的窗口显示「未知」和空进度条。Claude Code 与 agy 账号持续展示推送或本地缓存的百分比与进度条，不按年龄隐藏；重置时间已过时清空该窗口并提示「已重置，待更新」。原始获取时间保持不变，旧值不代表新窗口的实时额度。Codex 继续检查缓存年龄与重置时间。

验证目录发现、身份去重、不同账号额度归属、未知数据与零额度区分、Codex 查询的配置目录、额度展示及构建。无需执行真实账号切换或测试账号切换流程。
