# Clio 多账号额度展示

## 最终范围

识别 Claude Code 与 Codex 的多个已有登录账号，并列展示每个账号的已用额度、套餐、更新时间、重置时间及查询状态。不增加账号切换、选中账号或跟随 Orca 当前选择的功能，也不测试切号流程。

## 接入方案

读取系统默认目录、Orca 托管目录，以及用户添加的配置目录。通过账号身份去重；目录只是查询上下文。Claude 使用账号和组织标识，Codex 使用账号标识。未知身份不得冒充系统账号。

复用客户端查询：Claude 传 CLAUDE_CONFIG_DIR，Codex 传 CODEX_HOME。凭据由客户端管理。查询与缓存按账号保存；失败显示未知，缓存有实际更新时间，不把未知显示成零。移除目录仅移除 Clio 接入记录。

「Claude Code 查询频率」下拉框包含「不自动查询」（默认）和各时间间隔，不另设开关或手动查询行。选择「不自动查询」时，各自动入口仅读取 Claude Code 本地缓存，不调用其 CLI。Codex 始终自动查询，默认每 30 分钟一次，通过「Codex 查询频率」独立调整；查询调度及缓存有效期分别使用对应工具的频率。

面板顶部的「账号额度」右侧提供刷新图标，每次手动查询所有账号一轮，不开启 Claude Code 自动查询，并跳过缓存复用；查询期间显示转圈并禁用按钮。关闭 Claude Code 自动查询后，尚未开始的 Claude Code 查询会跳过，Codex 查询继续。停止自动查询不清零缓存有效期。

开启自动查询时，Claude Code 优先读取各账号本地额度缓存，有效缓存不启动 CLI；缓存缺失、账号归属不明或不匹配、超过设置的额度查询间隔、或额度窗口已重置时，才在该账号目录执行 `claude -p /usage`。执行时禁用工具、MCP、设置来源和会话持久化，等待进程成功退出后读取有效缓存，保留原始获取时间；超时或未得到有效缓存则查询失败。后台失败重试按账号限频。

## 展示边界

额度卡片按账号显示，历史 Token、费用表示本机汇总。主面板移除历史活跃热力图，账号额度采用紧凑布局，身份与套餐在首行，5 小时与本周已用百分比及进度条并列，下方直接显示各窗口的数据获取时间与重置倒计时。刷新按钮旁显示最近一份额度数据的实际获取时间，读取缓存不更新时间；跨日数据标明日期。同一快照里的两个窗口共享获取时间。状态和重置次数通过悬停查看。菜单栏两工具圆环同步显示已用比例，保留默认账号口径，提示中标明默认账号。账号较多时额度区域可滚动。

## 验证

账号按 Claude Code、Codex 分组排列，组内沿用发现顺序。5 小时或周额度窗口未返回时隐藏对应项。全部窗口均未取得时显示查询中或额度未知。Claude Code 关闭自动查询时，账号卡片持续展示本地缓存的百分比与进度条，不按缓存年龄隐藏；重置时间已过时保留上次结果并提示「已重置，待更新」。原始获取时间保持不变，旧值不代表新窗口的实时额度。自动查询模式及 Codex 继续检查缓存年龄与重置时间，展示策略不改变 CLI 查询所用的缓存有效期。

验证目录发现、身份去重、不同账号额度归属、未知数据与零额度区分、每个 CLI 查询的配置目录、额度展示及构建。无需执行真实账号切换或测试账号切换流程。
